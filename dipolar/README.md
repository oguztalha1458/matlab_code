# Dipolar Tonks–Girardeau Gazı

Tonks–Girardeau gazına dipolar çekim ekler ve taban durumunu sanal zaman yöntemiyle bulur. λ = 0 iken tuzak kalkar ve kendi kendine tutunan bir damlacık oluşur (Maciej Łebek'in tezi, denklem 3.10).

**Kullanım:** Üç dosya aynı klasörde olmalı. `GP_1d_dipolar.m`'nin başındaki parametreleri (`N`, `gdd0`, `lamd`, `eta`, `tau`) ayarlayıp çalıştırın. Büyük N için `tau = 1e-5` kullanın.
