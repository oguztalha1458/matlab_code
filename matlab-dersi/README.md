# Kök Bulma Yöntemleri

MATLAB dersindeki sayısal kök bulma yöntemleri. Her dosya f(x) = 8 − 4.5(x − sin x) = 0 denkleminin kökünü (x ≈ 2.4305) bulur ve adımları tablo olarak yazar.

| Dosya | Yöntem | İterasyon |
|---|---|---|
| `bisection.m` | İkiye bölme | 17 |
| `regula_falsi.m` | Regula falsi | 7 |
| `newton_raphson.m` | Newton–Raphson | 3 |
| `secant.m` | Secant (kiriş) | 4 |
| `fixed_point.m` | Sabit nokta iterasyonu | 44 |

**Kullanım:** Dosyayı MATLAB'da açıp Run'a basın. Fonksiyonu, başlangıç değerlerini ve toleransı dosyanın başından değiştirebilirsiniz.
