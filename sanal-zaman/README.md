# Harmonik Tuzakta Tonks–Girardeau Gazı

Tek boyutlu, güçlü etkileşimli (Tonks–Girardeau) Bose gazının harmonik tuzaktaki taban durumunu sanal zaman yöntemiyle (imaginary time propagation, split-step Fourier) bulur. Kamil Erkan'ın tezindeki denklem 3.9'u çözer.

**Kullanım:** Dört dosya aynı klasörde olmalı. MATLAB'da `GP_1d` yazıp çalıştırın ve başlangıç için 1 (Gauss) ya da 2 (Thomas–Fermi) seçin. Parametreler (`N`, `tau` ...) dosyanın başındadır, sonuç `.dat` dosyasına kaydedilir.
